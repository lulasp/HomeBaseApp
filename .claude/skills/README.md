# Skills

Project skills, invocable as `/<name>`. Each skill is a folder containing a `SKILL.md` with frontmatter (`name`, `description`) followed by instructions.

Skills in this project:

- **/new-feature** — scaffold a feature the way pantry/grocery/bills are built: screen folder, Firestore service functions + rules + indexes, navigation entry, tests.
- **/add-service** — add an external HTTP API module in `src/services/` (env-based or per-user key) with pure testable helpers and tests.
- **/deploy-rules** — consistency-check, validate, and deploy `firestore.rules` / `firestore.indexes.json` via the Firebase CLI.
- **/run-app** — start the Expo dev server or a native build and verify a change in the running app.
